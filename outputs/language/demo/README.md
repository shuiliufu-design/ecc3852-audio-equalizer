# SYNTHETIC DEMO

This directory was generated by the experiment pipeline. Synthetic demonstrations verify the implementation and do not constitute music-experiment evidence.

`results.json` records source hashes, actual sample ranges, analysis definitions, filter coefficients and measurements. `config_used.json` records the run configuration. Figures and raw_analysis refer to signals before the shared export attenuation.

Schema version 2: CSV estimated_export_peak_fs is the peak predicted before PCM quantization; decoded_export_peak_fs is measured from the saved WAV. Small differences arise from quantization.

Every WAV uses the same gain: 1.000000000 (0.0000 dB). Presets are not normalized individually. comparison_original.wav is a separate reference copy; the source file is preserved.

Timestamps are relative to the selected segment start; add source.start_s for source-file time. The highest significant frequency is estimated using an explicit relative threshold. It depends on noise, window leakage and threshold choice, and is not an exact bandwidth boundary.
