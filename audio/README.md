# 音频文件约定

正式音乐尚未选择。当前合成音频只用于验证，不作为歌曲实验的替代。

- `original/`：保存未来正式音乐的原文件，保留文件内容；记录来源、文件名、采样率、声道和时长。
- `demo/`：保存程序生成的 synthetic 测试信号；文件名和结果中明确标记 demo。
- 处理后音频放入对应的 `outputs/` 实验目录，避免覆盖输入。
- 如裁剪片段或转换格式，保留原文件，记录原曲起止时间及转换参数；片段内部时间与原曲时间应能相互对应。
- 首次读取后检查非空、有限数值、合理采样率和声道；人工试听是否正常应由实际试听后记录。

选曲时可优先考虑你熟悉、能取得本地文件、同时有低频、中频旋律或人声及高频成分的音乐。开发片段可先用 30–60 秒；这是开发建议，作业原文没有规定该时长。
